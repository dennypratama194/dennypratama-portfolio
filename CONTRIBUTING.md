# Contributing

Use Node.js 22+ and npm ci. Run npm run verify before a pull request. Explain
what changed and how it was checked. Use sample data only. Never submit keys,
database exports, visitor records, private client assets, or .env files.

Database tests require a disposable awards_test database. Set TEST_DATABASE_URL,
then run npm run test:db. Never point tests or db:setup at a production database.

Code contributions use MIT. See ASSETS.md for branding and content exclusions.
